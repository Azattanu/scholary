# Scholary — scholary.kz

Калькулятор вероятности поступления за рубеж со стипендией для казахстанцев.
Квиз (3 ветки: бакалавр/магистратура/PhD) → две вероятности по каждой программе →
персональный отчёт по секретной ссылке → оплата TipTop Pay → доставка WhatsApp + email.

- Фронт: статика (HTML/CSS/vanilla JS), деплой GitHub Pages / ps.kz
- База и бэкенд: Supabase (см. `supabase/`)
- Логика отчёта: `js/report-engine.js` (одна и та же в браузере и в Edge Functions)
- Запуск в прод: **ЗАПУСК.md** · Деплой и настройка: **README-DEPLOY.md**
